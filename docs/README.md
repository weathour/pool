## ★ 三份必读（其他都可以跳）

1. **[00-一句话版本](00-一句话版本.md)** —— 一段话讲清整个系统。**读这一份就能跟别人解释。**

## 怎么读这些文档

**它们不是规范，是判断记录。** 包括**判断错的地方**——比如：

- 01 里记着"周期结算是循环引用"这个我自己写出来的矛盾
- 22 记着 SHA-256 这条路的实测结果（三条链全断）
- 15 记着"我把这个项目读窄了"的自我修正

**为什么保留错的：** 因为"什么被排除掉了"比"选了什么"更能说明问题。
一份只有结论没有过程的文档，读者无法判断该不该信它。
