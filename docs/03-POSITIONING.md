> 合并自 `12-初心.md`、`14-平台定位.md`、`15-初衷与目标诊断.md`、`11-仓库形式-完全公开.md`、`16-开源镜像.md`。
> 五份是同一主题（"这个项目是什么、要做成什么"）在不同轮次的产物，**后面的推翻过前面的**。本文以**最终结论**为准；被推翻的方案连同推翻理由一起保留——"为什么不做 X"和"选了什么"同样重要。

## 一、一句话

> **把自己攒下的资料、经验、和处理资料的方法放进一个公共的地方，并且给"想一起做事的人"一个不用互相认识也能对接的入口。**

只有仓库 → 别人看完就走，**没人留下**；只有平台 → 热闹但没东西，**变成普通群**。
形式 = **一个公开的 git 仓库 + 四份 JSONL + 一个校验器**；产出物 = **"可验证知识单元"的生产单元**——别人卖答案，它卖"这个答案什么情况下是错的"。

| 层 | 内容 | 本质 | 特征 |
|---|---|---|---|
| 仓库层 | 智库（提问/回答/评价）、硬件基建（服务器、域名、机器人、资料处理）、资料保存与处理（语料、卡片、档案、账本） | 公共品 / 公摊资源 / 存量 | 答案不因被多人看而减少；成本已发生，多一个人用不增加成本；越用越值钱 |
| 协作层 | 招募板（贴公告、互相联系）+ 结算 | 匹配市场 | 要定价、要成交、要清算 |

**"协作申请"四个字是钥匙：发起单位不是"人"，是"需求"和"提议"。** 链条是 `有人提出需要什么 → 其他人看到 → 评价、建议、或加入 → 形成协作`。**这条链里没有"审批者"**——没有机构决定"你能不能来"，只有"这个需求/提议有没有人接"。

## 二、它不是什么 / 是什么

| 不是 | 是 |
|---|---|
| 一个社群 / 一个容器 | 一个知识项目；**"社群"是这个目标的容器，不是目标本身** |
| 一个工具站 | 一条能产出可核验结论的流水线 |
| 一个哲学知识库 | **一条能让人和模型协作产出可核验结论的流水线**——语料受版权约束，流水线不受 |
| 内容转售生意 | 别卖内容，卖那条能产出内容并留下证据链的流水线 |
| 邀请制俱乐部 | 完全公开的仓库，**"成员"这个概念已经消失**（见 4.2） |
| 靠"去中心化"标榜的组织 | 多中心分权 / 席位轮换 / 按物不论人（见 4.4） |

**三层目标，从最可靠到最不可靠**（事实层与资产证据见 5.1）：① **事实层（可断定）**——把私人整理的、不可验证的哲学知识，变成公共的、可验证的知识资产（*一个想传播观点的人不会这么干，一个想让观点被检验的人才会*）；② **动机层（高置信推断）**——验证"这套方法能不能真的产出站得住的东西"，而不只是"这套内容对不对"，核心命题是**人和模型的协作，在足够严格的证据纪律下，能产出比人单独或模型单独都更可靠的知识**；③ **结构层（低置信，可被直接否掉）**——"社区"这个词可能是借来的：仓库里跑得最顺的是**纪律**和**会计**，**没有一丝"集体生活"的痕迹**（没有讨论、没有投票记录、没有成员名单、没有会议纪要，四个月里只有一个人在做决定）。而群聊里最热的是 credit 记账与"谁能进来"（会计与资格问题），**被跳过的是退出、资产归谁、争议怎么裁、失败了怎么办**（如果要长期共同生活，这恰恰是最需要谈的）。

**产出物定位的三个候选：**

| 候选 | 定位 | 要害 |
|---|---|---|
| **P-A 知识生产合作社（推荐为主）** | 把"人和模型的协作产出"变成**可核验、可计价、可交易的知识单元** | **组织形态跟着产出物走，而不是反过来**；没有社区、没有会员、没有元老院，只有"谁在这期里产出了被验证的东西" |
| P-B 知识工场（外包式） | 接单生产可核验知识单元的乙方，人力和模型都是可替换的产能 | credit = 纯计件工资、人机同价、谁产出谁拿；现金流直接、无需社区运营，但**会退化成内容农场**；单独做没有护城河，只能作为 P-A 接单时的执行形态 |
| P-C 训练/认证机构 | 教人怎么和模型协作做可核验研究 | 卖的是能力转移，边际成本近零；中文市场付费意愿真实、语料天然是教材；但依赖个人品牌、启动慢、**同样踩版权**（教材不能直接用 B 站转写） |

**推荐 P-A 为主 + P-C 做第一批现金流**：P-A 的产出物（知识包）正好是 P-C 的教材，P-C 的学员正好是 P-A 的产能来源——同一条流水线，两个出口。

## 三、要解决的问题

**稀缺的不是知识，不是算力，不是答案：是"陌生人之间的信任"。** 仓库解决一半——**让一个人说过的话变成可查的**；协作申请平台解决另一半——**让两个人不用先认识就能开始合作**。**邀请制是错的方向**：它只在已有熟人网络里分配信任，不生产新的信任。

**为什么以前做不到、现在能做了：** 一个人做仓库很自然（260 个提交就是证明）；但"仓库 + 匹配"一起做，历史上只有大组织干得成——**匹配成本（介绍、撮合、定约、验证、催账、处理赖账）随人数指数上升**。小群体做这个，结果一定二选一：变成死资料库，或变成活的聊天群加一个没人看的资料夹。**agent 第一次改了这个成本结构**（撮合、初筛、验证、记录、催办现在可以自动化），**所以这是 2026 年的对话，不是 2016 年的。**

**两层必须用不同性质的账，混了就两层都废。** 语料里正好有这个区分：*"这是纲领，那么最左边是习俗再往那边退就本能了……最往下面就是交易了，交易有对价的行动或者有偿行动。"* —— 庶政学预备工作（1），`library/manifests/shuzheng-practice-agent-reviewed-evidence.jsonl:2`（`analysis_status: V`，仅作有界释义）。纵轴就是"交易（有偿 / 有对价）↔ 无对价行动"，两层正好落在两端：

| | **仓库层**（智库 + 基建 + 资料）→ 记**贡献值** | **协作层**（招募板 + 结算）→ 记**结算额** |
|---|---|---|
| 行动性质 | **无对价**——我回答你，不图你什么 | **有对价**——我加入你的项目，要拿回报 |
| 能不能定价 | **不能**。定不了"一个好回答值多少钱" | **必须**。不定价就没人来 |
| 记录方式 | 按贡献记账（reputation） | 按成交结算（payment） |
| 失败形态 | 定价了 → 提问变下单，**没人愿意答** | 只记账 → 变互相吹捧，**匹配市场死掉** |
| 记什么 | 你让公共池变大了多少；**不可转让、不可兑换、只增不减**；用途 = 席位、声誉、话语权重 | 一次协作里谁该拿多少；**可清算、可对价、有债权债务**；用途 = 真金白银的分配 |
| 出处 | = v3 的 credit（双层衰减那套） | **v3 完全没设计，是真空白** |

**结论：credit 必须分两种，不能是一种。招募板没有结算，就只是个留言板。**

**"成员"这个统一身份也是多余的**：服务对象可以不同——有的是**提问者、供给者、接单者、复核者**。一个人可以同时是四个，但不必先成为"成员"。

**最后一条问题诊断：你们不缺组织设计，缺的是"这个东西被外面的人看见并认了"。** 而组织设计是这个问题的**拖延方式**——它让人感觉在推进，而实际上库没有变大。语料对自己最狠的一句判词就是这个意思：**organization for practice by itself**（`library/themes/governance-law-bureaucracy/governance-law-bureaucracy-synthesis.md:15`）。**搭组织不是实践，让库变大才是。**

## 四、五个"曾被推翻的定位"

### 4.1 定位一："纯知识生产项目，社群只是容器"（`15`）→ 被 `12` 推翻

上一版读法：重心放在"260 个提交、可核验、证明方法论"上，于是得出"这是一个知识生产项目，社群只是容器"。**它抓住了资产，但漏了一半：仓库里的东西是用来被用的，而"被用"需要一个入口。**

| 你说的 | 上一版的处理 | 实际地位 |
|---|---|---|
| 资料 | 抓住了（语料、细读卡、主题档案） | 仓库的**存货** |
| **经验** | **完全漏了** | 仓库里**最不可复制**的部分 |
| **服务** | 当成"功能清单" | 其实**就是那个入口** |

**"经验"漏得最厉害**：真正独有、别人抄不走的，不是哲学内容（那是 B 站讲者的），也不是工具代码（那是可复制的），而是——**怎么让模型产出可核验结论的那套操作经验、194 个审查条目背后的判断标准、27,500 行工具踩过的坑、哪些做法是死路及为什么**。**"资料"是可以买的，"经验"不能。**

**群聊里说出来的目标是"建一个社群"**（公摊成本做基建、基建成果共享；服务 = 智库 / 硬件基建 / 招募板；义务 = 不捣乱、平摊、出力；成员 = 邀请制、2 元老同意；谁来设计平台和架构然后租服务器搞）。**但唯一暴露动机的一句是"后续我肯定是要再拉人的"**——说出来的目标是**容器**，实际发生的动作是**内容**："想让自己做了四个月的东西有人接着做、有人认"。**把容器当成目标是危险的，因为它会让人以为搭好了架子就等于做成了事。**

**推翻后的结论：它同时是一个仓库和一个协作申请平台。** 顺带修正的还有顺序（`14` §0）：必须是 **产出物 → 平台定位 → 治理 → credit 计量**，v2 的顺序是反的——因为**治理形式必须匹配产出物**：credit 若定成"对公摊资源的提取权"，就预设了产出物是内部自用的；产出物要对外卖，credit 就必须能对应**收入分配**，否则贡献者拿不到回报，第一批人就会走。

### 4.2 定位二："元老院 + 邀请制 + 2 元老同意"（群聊原话 / v1-v3）→ 推翻

原主张：成员 = 邀请制、2 元老同意；元老院管准入与清退。四条推翻理由：

1. **管错了对象**（`12`）：元老院管"谁能进来"，实际机制管"什么东西有人接"——**一个管资格，一个管匹配**。准入制度是治"匹配失败"的错药：匹配失败的原因是"没人看得见需求"和"没人信得过对方"，不是"坏人太多"。
2. **不需要"准入"这个概念**（`15`）：需要的是"你的知识包过不过复核"。**人不是被批准进来的，是被产出带进来的。**
3. **语料里没有依据**（`14` §5.7，缺口全表见 6.8）：**"元老院"在 curated 层（clean-markdown + library）零命中**，全库仅 6 次且全在 `corpus/bilibili-asr/` 原始 ASR（如 `BV1TW42197z3__...txt:107`）；"贵族共和""制宪""建党""秘密结社"同样只在 ASR。**"元老院""邀请制""公摊""义务"这些词的出处不是语料，是二十世纪中国的组织语汇**——是从别处借来的现成外壳；**借外壳不是错，危险在于把外壳当成了内容**。
4. **完全公开取消了这个边界**（`16` §5.2 / `11` §3.2）：元老院一直感觉不对，是因为**它假设了一个封闭的边界，而开源把这个边界取消了**——不需要邀请制（代码和数据摆在那里，能读懂、愿意接着做的人自然会出现）、不需要元老审核（**贡献本身就是门槛**）、不需要宣传（镜像和引用会自己扩散）。

**最终形态：`members.jsonl` → `keyring.jsonl`（公钥目录，不是成员名单）**：`{"pubkey":"ed25519:...", "handle":"雁", "since":"2026-09-16", "status":"active|retired"}`。名单 = 有边界、要审批、进不去就用不了；目录 = **没有边界，任何人加一条自己的记录就能开始干活**；**"移除"也不需要**——加一条 `status: retired` 就行，**历史记录里的签名永远有效，因为它当时确实是他签的**。

配套改动：把"招募成员"改成"让产出可见"——**"拉人最有效的办法不是元老院投票，是把仓库挂出去，让方法本身成为筛子"**（`15`）；完全公开之后，这句话变成了字面意思（`11` §4.1）。

> **完整论证（含 13 的全部语料锚点、被否方案的原文形态）在 [`05-GOVERNANCE.md` 第四节](05-GOVERNANCE.md)。这里只留定位层面的结论。**

### 4.3 定位三："分层公开"（v3 时期主张：public 层 + private 层，完整论证见 `16`）→ 被 `11` 推翻：完全公开

**原方案的论证：** 前几轮所有的法律简洁性都建立在"**内部使用** → 不需要备案、不需要处理版权、不需要注册主体"这一句上；开源之后，这一句直接失效。

| 之前说"不是问题"的 | 开源后的状态 |
|---|---|
| B 站转写原文可以进池子 | ❌ **不能公开分发** |
| 不需要 ICP 备案 | ⚠️ 若挂在自己域名下对外可访问，**又回到备案问题** |
| 不需要法律主体 | ⚠️ 一旦有公开的义务与回报约定，性质就变了 |

于是提出分层公开：

```
public/   requests.jsonl（公告板，本来就设计成不含人名）· deliverables.jsonl（交付物，本来就不含人名）
          · cycles.jsonl（周期结算 + Merkle root）· 结论与锚点 · tools/ docs/ policies.jsonl
private/  members.jsonl（成员身份）· credits.jsonl（账本，含人名）· maintainer-log.jsonl（维护者操作）
          · corpus 原文（B 站转写，只在本机）
```

- **★ 这个分层几乎是免费的**：前面定"单子上不写人名"的时候，public 层就已经天然准备好了——当时那个决定是为了"谁产出谁说话"，现在它顺便解决了开源合规问题，**是那一轮最值钱的副产品**。
- **它不削弱可验证性**：public 层的 `cycles.jsonl` 带着每期的 **Merkle root**，而那个 root 由**全部六份文件**算出。任何人拿到 public 层都能验证"这一期的完整状态是那个哈希"，只是看不到 private 层的内容。这叫**"可验证但不公开"**。
- **credit 里有人名，两个选择**：A. credit 不公开，只公开每期的**汇总结算**（总数、占比分布），代价是外部无法核验单条 credit——**当时建议 A**；B. 公开但用假名，代价是假名在长期行为下**会被推断出身份**（谁写的东西风格很明显）。
- **谁说了算**：不能既说"人人可克隆"、又说"以我这份为准"，所以**不设权威，设证明**——每期结算由维护者发布一个**签名的 Merkle root**，镜像持有者验证自己的副本算出来的 root 对不对得上：对得上即可信，对不上就是被改过（或结算后又被追加了东西）。**信任的对象从"仓库"变成了"那个签名的 root"**——谁的仓库都可以是权威，只要 root 对得上；维护者能改自己的副本，但所有镜像的 root 会对不上。
- **写权限分三层**：代码 / 文档 / 规则 = 任何人（提 PR，维护者合并）；`data/` 文件 = **单写者**（或少数几个签名者），每条记录必须有有效签名，**未签名 / 签名无效的追加直接判失败**；镜像 = 任何人，克隆即镜像，无需许可。**代码是开放的，数据是受控的，验证是开放的**——而"数据受控"不需要任何权限系统，**签名本身就是权限**。

**推翻：新前提是"完全公开，不分层，内部没有版权"。**

| 分层方案里的东西 | 完全公开之后 |
|---|---|
| private 层（身份 + 账本 + 原文） | **取消**。没有"内部资产"和"已发布"的区别，只有"在 main 上"和"不在 main 上" |
| 六份文件 | **降到四份**：`requests` / `deliverables` / `credits` / `keyring` |
| `cycles.jsonl` + 每期 Merkle root | **删除**，周期结算改用**签名 git tag**（commit 的 SHA 覆盖整棵树）：`git tag -s cycle-2026-Q4 -m "本周期 12 张单，成案 5 件，打回 3 件"` + `git push --tags`——**一条命令，替代一整个文件** |
| `members.jsonl` | → `keyring.jsonl`（见 4.2） |
| `maintainer-log.jsonl` | 简化成 `MAINTAINERS.md` + git log，不需要独立文件 |
| `prev` 字段 | **去掉**（git 的 commit 链就是那条链；`prev` 是为"没有 git 的世界"设计的。唯一保它的理由是数据脱离 git 单独存在时仍可自验，但完全公开、随时能 clone，这个理由不成立） |
| credit 只公开汇总 | 失去载体（不再有私有层放明细） |

**但有一件事必须摆在明处（`11` §0）：仓库是公开的，等于 363 篇 B 站转写是"重新发布"，而不只是"自己看"。** 这不影响自己用，也不影响开发，**但它是一个已经做出的选择，不是没发生的事**。雁雁 09-16 说过"好像人多了得备案……那也是小事，又不造反"——逻辑相同：**按自己的判断承担，但要让这个选择是"知情的"。**

### 4.4 定位四："去中心化"（v1/v2 的定位词）→ 显式撤回

语料的术语纪律里，`去中心化` 是一个**被锁死的术语**，不许平移到一般组织设计：*"**forbidden mix：不要把该义项写成一般组织去中心化**；这里是向上负责转为向当下人民负责的历史妥协。"* —— `library/concepts/core-terms.md:1322`（`term:去中心化:s01`，source row 315）。仓库里还有一个**专章**论证"去中心化救不了科层化"，整节标题就叫《去中心化的科层主义》：*"一个统治共同体他是会去中心化的。你哪怕有一个头头，他就算他是个 pope……但是他其实又背叛了这个至善……**因为 bureaucratism，他就是理性。**"* —— `corpus/clean-markdown/3_观念论_作为一个现代人_该怎样思考哲学/3-3_复习课/3-3-4_虚构的生存论/3-3-4-2_去中心化的科层主义/0251_3-3-4-2_去中心化的科层主义_p6455.md:18,24`（同一处 `:18` 还有一句判词："没有用，it doesn't work"）。意思是：**头头的"第一人称意识"本来就是去中心的、自己都不知道自己在干什么——所以"去中心化"不是科层化的解药，科层化恰恰是从"连自己是谁都不知道"里长出来的。**

- ❌ 不再把"去中心化"写成平台定位或组织特征；✅ 改用**"多中心分权""席位轮换""按物不论人"**这类描述性说法。
- ✅ 要沿用雁雁原话，必须复述为他的原意：**"还没必要中心化"**——这是**发生学判断**（现在这个规模不需要），不是**规范性主张**（中心化是坏的）。这两件事完全不同：前者认同，后者语料明确反对。

**必须并置的反面证据（不许只引一边）——语料对"创始人核心"有一条最强的正面命令：** *"**你们一定要中心化，必须是中心化的，因为你们必须得磋商，而且你必须是拧成一股绳，有主心骨的、有一个最强的人过来拍板的、要有他决策权的。**"* —— `corpus/clean-markdown/4_实践/4-1_复习/4-1-2_灌输/4-1-2-3_正派青年的交往与团结/0287_4-1-2-3_正派青年的交往与团结_p7452.md:30`（同文件 `:15` 还给了配套的保密纪律："藏要藏的深，一定要藏的深，永远不要公屏嘲讽"。）处理方式不是折中，是分工：

| | 语料主张 | 适用范围 |
|---|---|---|
| **决策** | 中心化，一个人拍板（N4） | **对外口径、客户谈判、危机处理**——这些事磋商成本必须低 |
| **记账** | 分权，多主体复核 | **知识包采纳、credit 确认**——这些事必须可核验、可申诉 |

**一个人做决定，但决定要落在账上。** 语料反对的是"名义上人人平等、实际上没法磋商"，不是反对"账要公开"。

### 4.5 定位五："credit = 对公摊资源的提取权"那一整套（清退程序 / 三院制 / 先搭账本 / 卖知识包）→ 逐项修正

| 原设计（v1-v3） | 改成 | 依据 |
|---|---|---|
| 元老院管准入与清退 | **准入不是核心机制**，核心是"申请与接单"的记录。**人不是被批准的，是被约到的** | `12` |
| 清退程序（阈值式，如"四年不出席才开除"） | **credit 双层衰减**：不产出就自然衰减，**没有审判、没有投票、没有申诉程序**——让位置自然空出来，而不是把人赶出去 | `14` §4.2 |
| 三院制（算力院 / 验证院 / 解释院） | 只需**两个功能**：谁供给资源，谁复核结论。"解释院"是多出来的——除非对外交付真的发生了 | `15` |
| （同一件事的另一种说法） | 也可读成**两院**：仓院（管池子）/ 约院（管结算与争议）；砍掉"解释院"的理由要改——**它属于仓库层，不属于协作层** | `12` |
| 一种 credit | **两种账**：贡献值（不可兑换）+ 结算额（可清算）。**这是最大的改动** | `12` |
| credit = 对公摊资源的提取权 | credit 是对的，但它的第一次真实用途不是买算力，是**记录"谁让这个库变大了"** | `15` |
| 先定 charter，再搭账本 | **先扩库，账本跟着库走。** 库停下来那天，账本就没意义了 | `15` |
| 先基建、后验证 | **先卖一单，再决定建什么**（见 5.4） | `14` §6 |
| 12 个月日落重议 | **保留** | 两轮共识 |
| 面向外部卖知识包 | **降级**：那是变现路径之一，不是初心。初心是**让这个池子被用起来** | `12` |
| 入伙：2 人提名 + 公示 7 天 + 90 天观察期 | **门槛必须是可损失的东西**，不能是承诺、仪式或表态：先出一份知识包（不是申请，是产出），再押一份可损失的东西（分摊预付，或一份知识包的独占权）。**不需要宣誓、不需要投票** | `14` §4.5 |
| "日落条款能避免僵化" | **撤回这个暗示**（见 6.4）：衰减制、日落、形式诚实都只是减速器 | `14` §5.2 |

> **credit 的算法、为什么不上链、它的两个特有病症 —— 都在 [`02-credit.md`](02-credit.md)。这里只讲定位层面的变更。**

**为什么清退必须靠衰减而不是靠程序：** 语料自己把阈值式清退点破了——*"……什么 Ti1 的时候，什么四年不出席才开除，你自己活了多少年？"*（row 282 `corpus/clean-markdown/4_实践/4-1_复习/4-1-1_资本主义史研究/4-1-1-3_国际性的理论协调/0282_..._p7320.md:94`，**"不出席才开除"这种阈值是荒谬的**，语料自己的判词）；另一边——*"你不要时刻想着一旁老人已经七老八十岁了……会被自己拖死。当时的苏联就是这样的，拖死。"*（row 334 `corpus/clean-markdown/4_实践/4-3_建设理想社会/4-3-3_战略-战役-战斗的统合/4-3-3-2_纪律教育/0334_..._p8418.md:29`）。但语料给不出解法——普查确认清退程序、退出程序、资产归属、争议仲裁**仓库里全部是空的**（唯一相关的都是 4-4 讲 VR 永生时代的虚构思想实验：去留委员会 / 归焉委员会 / aging 机制，**不可迁移到现实小团队**）。所以这里必须自己设计：

```
活跃 credit —— 本期（如 90 天）有产出的，全额有效，可换取资源与席位
休眠 credit —— 停产后按半衰期衰减（如 180 天减半），不可换取席位，仍可换取资源
```

| 问题 | 如何被解决 |
|---|---|
| 名义忠诚无约束力 | 语料说"第一人称忠诚陈述本身不足为据"，权力依赖**可损失的担保**（`shuzheng-practice-agent-reviewed-evidence.jsonl:12`）→ **休眠衰减就是那个可损失的东西**，而且不需要任何人来没收 |
| 清退程序写不出来 | **不用写。** 不产出 → 自然衰减。没有审判，没有投票，没有申诉程序 |
| 橡皮图章 / 内圈化 | 席位只在期末按**活跃 credit** 重新计算，不设终身席位 |
| 老人政治 | 不产出就衰减，新人能快速追赶。**加速上升通道不需要给新人特权，只需要让老人自然减速** |
| 继承不可能 | 语料明说创始权威**不可继承**（`0300:69`"这个遗产不可继承……是不可延续"）→ **那就别继承，重新分配** |

**这是"激进"的真正所在：不是把人赶出去，是让位置自然空出来。** 语料说"他可以体面的退场，不参与共同体事务"（row 352），也给了"到场服务、出仓日"这种机制（`0352_..._p8776.md:14,19,24,34`）——衰减制是它的现实版，比"每年体检打分"温和得多，因为它不需要任何人做判断。**入伙门槛的依据也不是仪式，是代价：** *"**你要入伙，那你就要付出代价。你付出代价的话，你就做出抉择。你做出抉择，你就什么立场。**"*（`corpus/clean-markdown/2_形而上学_.../2-2-1-4_摩尔唯心主义.../0124_..._p3352.md:214`），与实践学那条 V 级记录互相印证：*"把支配力的维持关联于**可损失的担保或代价**，并认为**第一人称忠诚陈述本身不足为据**"*（`library/manifests/shuzheng-practice-agent-reviewed-evidence.jsonl:12`）——**合起来是一条硬规则：门槛必须是可损失的东西**，休眠衰减就是"可损失的担保"的**自动化版本**。**"准入看物不看人"的正当性依据：** *"好的就是贵族政体，坏的就是寡头政体。妈的，你怎么去区分什么叫贵族，什么叫寡头？评判体系在哪里？"*（row 106 `corpus/clean-markdown/2_形而上学_.../0106_..._p2730.md:148`）——**"贵族 vs 寡头"没有独立评判体系，那唯一的出路就是不靠身份评判，靠产出评判。**
